# 📥 INSTALLATION

## 1️⃣ Download CoreLua

Download the latest version of **CoreLua** from the GitHub repository.

Extract the downloaded `.zip` file somewhere on your computer.

---

## 2️⃣ Enable Developer Mode

Open your browser and go to the **Extensions** page.

Click the:

**⋮ → Extensions → Manage Extensions**

Then enable:

> 🛠️ **Developer mode**

---

## 3️⃣ Load the CoreLua Extension

Once **Developer mode** is enabled:

1. Click **Load unpacked**
2. Select the **CoreLua extension folder**
3. Confirm the folder
4. The CoreLua extension should now appear in your extensions list

Make sure you select the folder containing the extension files, not the `.zip` archive itself.

---

## 4️⃣ Start the CoreLua Bridge

Go inside the CoreLua folder.

You should find:

```text
start.bat
```

Double-click:

```text
start.bat
```

A terminal window should open.

**Keep this window open while using CoreLua.**

---

# 🎮 5️⃣ OPEN ROBLOX STUDIO

Launch **Roblox Studio**.

Open your Roblox project/place.

Then go to the Studio settings and enable:

> 🌐 **Allow HTTP Requests**

This allows Roblox Studio to communicate with the CoreLua bridge.

---

# 🤖 6️⃣ CHOOSE YOUR AI

Open one of the supported AI services:

* 🔵 **DeepSeek**
* 🟣 **Gemini**
* 🟢 **Kimi**

Then open the CoreLua interface / extension.

---

# 🌉 7️⃣ START THE BRIDGE

```text
AI

```

# 🛠️ TROUBLESHOOTING

### ❌ The extension doesn't appear

Make sure:

* Developer Mode is enabled
* You selected the correct CoreLua folder
* You used **Load unpacked**
* The extension folder contains the required extension files

---

### ❌ `start.bat` doesn't work

Make sure:

* You extracted the complete CoreLua folder
* You are launching `start.bat` from the correct directory
* Required dependencies are installed
* Windows is not blocking the file

---

### ❌ Roblox Studio doesn't connect

Check that:

* Roblox Studio is running
* Your place is open
* **Allow HTTP Requests** is enabled
* `start.bat` is still running
* The CoreLua bridge is started
* Your AI service is connected
